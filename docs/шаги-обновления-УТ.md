# Шаги обновления УТ (по твоей части)

Обновление под пакет «Разделение прав агента + заявки на новых клиентов»
(18.09.2026). Сервер и APK я обновляю сам; здесь — только то, что делается в
**Конфигураторе УТ** и в данных. Порядок важен.

Исходники расширения — `smartsale/1c/расширение SmartSale`. Обработка —
`smartsale/1c/обработки/SmartSale_ПриёмЗаявокКлиентов/SmartSale_ПриёмЗаявокКлиентов.epf`.

---

## 1. Объекты расширения (создать/дополнить)

### 1.1. Справочник `SmartSale_ЗаявкиКлиентов` (новый)
Назначение **Собственный** (Native), префикс `SmartSale_`, код есть, иерархии нет.
Наименование — стандартный реквизит (название точки). Реквизиты (пояснение:
`Catalogs/SmartSale_ЗаявкиКлиентов/Ext/пояснение.md`):

| Имя | Тип |
|---|---|
| `Агент` | СправочникСсылка.Пользователи |
| `Адрес` | Строка (0, перем.) |
| `Телефон` | Строка (50, перем.) |
| `КонтактноеЛицо` | Строка (100, перем.) |
| `ИНН` | Строка (20, перем.) |
| `Широта` | Строка (20, перем.) |
| `Долгота` | Строка (20, перем.) |
| `Комментарий` | Строка (0, перем.) |
| `КлючИдемпотентности` | Строка (50, перем.) |
| `ДатаЗаявки` | Дата (состав «Дата и время») |
| `Обработана` | Булево |
| **`КлиентСоздан`** | **СправочникСсылка.Партнеры** |

⚠️ `КлиентСоздан` обязателен — без него АРМ не пометит заявку исполненной
(обработка это проверяет и выдаёт понятное сообщение).

### 1.2. Регистр сведений `SmartSale_СкладыАгентов` (дополнить)
Добавить **пять реквизитов/ресурсов типа Булево** (пояснение:
`InformationRegisters/SmartSale_СкладыАгентов/Ext/пояснение.md`):

`ПравоЗаказы`, `ПравоОплаты`, `ПравоДоставка`, `ПравоАудит`, `ПравоЗаявкаКлиента`.

Это **независимые флаги** — агенту можно включить любой их набор (хоть все пять,
хоть ничего), это не одна роль.

### 1.3. HTTP-сервис `smartsale` — шаблон `/customer_requests`
Уже в `HTTPServices/smartsale.xml` (URLTemplate `/customer_requests`, метод POST →
`customerRequestsPOST`). Отдельно создавать не нужно — придёт при загрузке
обновлённого объекта HTTP-сервиса.

## 2. Загрузить обновлённые модули расширения
- Общий модуль **`SmartSale_Обмен`** (приём заявок `ПринятьЗаявкиКлиентов`;
  `ЗаписатьКоординаты` стал экспортным — его теперь зовёт и обмен, и АРМ).
- HTTP-сервис **`smartsale`**: модуль (обработчик `customerRequestsPOST`,
  выборка `УчёткиАгентов` теперь отдаёт 5 прав) + объект сервиса (URLTemplate).

---

## 3. Права (роли расширения)
- **Учётке обмена** (`smartsale`): чтение новых реквизитов `Право*` регистра
  `SmartSale_СкладыАгентов`. Справочник `SmartSale_ЗаявкиКлиентов` учётке обмена
  **НЕ** выдавать — он пишется привилегированно.
- **Роли менеджера** (кто разбирает заявки): чтение/изменение
  `SmartSale_ЗаявкиКлиентов` (и его реквизитов), создание `Партнеры` и
  `Контрагенты`.

---

## 4. Обновить конфигурацию базы и ЗАКРЫТЬ Конфигуратор
Обновить конфигурацию (F7 / «Обновить конфигурацию базы данных»), затем
**закрыть Конфигуратор** — открытый держит блокировку обновления расширения, и
объекты в рабочих сеансах не обновятся.

---

## 5. Заполнить данные
1. **Права по агентам**: в регистре `SmartSale_СкладыАгентов` каждому агенту
   проставить нужные флаги `Право*`. Пока у агента не взведён ни один флаг —
   приложение работает на умолчаниях (всё разрешено, кроме доставки); блок прав
   начинает действовать по агенту только после первой галочки. Это защита от
   блокировки уже работающих агентов при раскатке.
2. **Координаты на карте** (для заявок): убедиться, что у контрагентов есть виды
   КИ с `ИдентификаторДляФормул` = `ГеографическаяШирота` / `ГеографическаяДолгота`
   — те же, что уже использует уточнение координат с телефона (Фаза C) и карта.
   Если есть (карта уже работала) — ничего не делать; АРМ пишет туда же.

---

## 6. Загрузить обработку АРМ
Открыть `SmartSale_ПриёмЗаявокКлиентов.epf` (Файл → Открыть) или подключить
дополнительной обработкой. Проверка: выбрать заявку → «Завести клиентов» →
в базе появляются Партнёр и Контрагент, телефон/адрес в КИ, координаты — на
карте, заявка помечена «Обработана».

---

## Проверка end-to-end
Агент в приложении (с включённым `ПравоЗаявкаКлиента`) шлёт заявку → обмен →
она видна в АРМ → менеджер заводит клиента → клиент приходит агенту при
следующем обмене (если у него этот агент основным менеджером).

---

## Не относится к этому пакету (осталось с прошлых эпиков)
Для полноты — эти шаги из более ранних доработок ещё ждут тебя, но к правам и
заявкам отношения не имеют:
- загрузить модули обмена «задания/доставка», снести справочник `SmartSale_Задания`;
- для MML: включить функциональную опцию «Использовать ассортимент» и завести
  форматы магазинов.

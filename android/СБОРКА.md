# Сборка приложения агента

Без Android Studio, из командной строки. Всё, что нужно, лежит вне проекта:

| Что | Где |
|---|---|
| JDK 17 | `C:\Users\USER\tools\jdk-17.0.20+8` |
| Gradle 8.11.1 | `C:\Users\USER\tools\gradle-8.11.1` |
| Android SDK | `C:\Users\USER\tools\android-sdk` |

Путь к SDK прописан в `local.properties` — файл машинно-зависимый и в
репозиторий не попадает.

## Разово: лицензии и пакеты SDK

Лицензии принимает человек, это юридическое согласие:

```
sdkmanager.bat --sdk_root=<SDK> --licenses
```

Затем пакеты:

```
sdkmanager.bat --sdk_root=<SDK> "platform-tools" "platforms;android-35" "build-tools;35.0.0"
```

## Сборка

```
gradle.bat assembleDebug
```

Готовый файл: `app\build\outputs\apk\debug\app-debug.apk`.

Скрипт `собрать.ps1` в этом каталоге делает то же самое, подставляя пути.

## Установка на телефон

Файл кладётся на телефон любым способом и ставится вручную — потребуется
разрешить установку из неизвестных источников. Через кабель:

```
adb install -r app-debug.apk
```

`adb.exe` лежит в `<SDK>\platform-tools`.

## Первый запуск

На экране входа три поля. Адрес сервера:

```
https://smartsale.31.207.45.93.sslip.io
```

Логин и пароль — учётной записи с ролью «агент». Устройство привязывается к
агенту при первом входе; отключить его можно в кабинете, на странице
«Агенты».

## Параллельная сборка выключена

В `gradle.properties` стоит `org.gradle.parallel=false`. Это не забытая
настройка: с параллельностью сборка дважды падала на

```
Could not move temporary workspace ... AccessDeniedException
```

Gradle переименовывает каталог в кэше артефактов, пока файл внутри ещё
держит антивирус. Модуль в проекте один, выигрыша от параллельности нет —
включать обратно незачем.

## Замечания

- Сборка debug, без подписи ключом. Для раздачи агентам нужен release и
  свой ключ подписи — создавать его должен владелец приложения.
- `usesCleartextTraffic` в манифесте больше не нужен: сервер за HTTPS.
  Убрать при первой правке.
- Обёртки Gradle (`gradlew`) в репозитории нет — сборка идёт установленным
  Gradle. Если понадобится обёртка: `gradle.bat wrapper`.

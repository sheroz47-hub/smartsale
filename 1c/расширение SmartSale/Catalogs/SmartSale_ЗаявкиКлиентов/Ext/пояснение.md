# Заявки клиентов SmartSale — объект расширения для Конфигуратора

Справочник, куда обмен складывает **заявки агентов на новых клиентов**
(обработчик `SmartSale_Обмен.ПринятьЗаявкиКлиентов`, метод сервиса
`/customer_requests`). Заявка — это ещё не клиент: менеджер разбирает её АРМ‑ом
`SmartSale_ПриёмЗаявокКлиентов` и по ней заводит типовых Партнёра и Контрагента.
Так мастер‑данные остаются под контролем офиса, а не создаются с телефона.

XML не прикладываю: справочник простой, быстрее и надёжнее создать мышью.

Назначение — **Собственный** (ObjectBelonging = Native), имя с префиксом
`SmartSale_`. Код (владелец нет, иерархии нет). Наименование — стандартный
реквизит, в него пишется название торговой точки.

## Реквизиты

| Имя | Тип | Назначение |
|---|---|---|
| `Агент` | СправочникСсылка.Пользователи | Кто прислал заявку (по нему станет `ОсновнойМенеджер` партнёра). |
| `Адрес` | Строка (0, перем.) | Адрес точки со слов агента. |
| `Телефон` | Строка (50, перем.) | Телефон точки/контакта. |
| `КонтактноеЛицо` | Строка (100, перем.) | ЛПР на точке. |
| `ИНН` | Строка (20, перем.) | ИНН, если агент узнал. Пусто → заведётся как частное лицо. |
| `Широта` | Строка (20, перем.) | GPS‑широта точки (снимается на телефоне). Строкой — как пришла. |
| `Долгота` | Строка (20, перем.) | GPS‑долгота точки. |
| `Комментарий` | Строка (0, перем.) | Примечание агента. |
| `КлючИдемпотентности` | Строка (50, перем.) | `client_uid` заявки. По нему обмен не задваивает заявку при повторной отправке. |
| `ДатаЗаявки` | Дата (состав «Дата и время») | Когда заявка принята в УТ. |
| `Обработана` | Булево | Менеджер завёл клиента → Истина. АРМ показывает только `Обработана = Ложь`. |
| `КлиентСоздан` | СправочникСсылка.Партнеры | Партнёр, которого завела заявка. Пусто, пока не обработана. |

## После создания

1. Учётке обмена права на этот справочник **не** выдавать — обработчик пишет его
   в привилегированном режиме (`SmartSale_Обмен.ЗаписатьЗаявкуКлиента`).
2. Роли менеджера дать чтение/изменение `SmartSale_ЗаявкиКлиентов`,
   `SmartSale_ЗаявкиКлиентов.Реквизит.*`, а также создание `Партнеры` и
   `Контрагенты` — под этими правами работает АРМ `SmartSale_ПриёмЗаявокКлиентов`.
3. Обновить конфигурацию, затем загрузить модуль сервиса с методом
   `/customer_requests` (URL‑шаблон уже в `HTTPServices/smartsale.xml`).

# Трек агента SmartSale — объект расширения для Конфигуратора

Регистр сведений, куда обмен кладёт **точки трека агента**: телефон в рабочие
часы фоново снимает координаты (интервал ~3 мин) и шлёт пачкой, обмен пишет их
сюда (обработчик `SmartSale_Обмен.ПринятьТрекАгента`, метод сервиса
`/agent_track`). По треку видно, где агент сейчас, сколько пробыл у клиента и
каким маршрутом реально прошёл за период. Читает регистр просмотрщик трека (АРМ).

XML не прикладываю: регистр простой, надёжнее собрать мышью.

## Регистр `SmartSale_ТрекАгента`

Назначение — **Собственный** (Native), имя с префиксом `SmartSale_`.

**Свойства:**
- **Периодичность** — «В пределах секунды» (одна точка = один момент времени).
- **Режим записи** — **Независимый** (без регистратора).

**Измерение:**

| Имя | Тип | Назначение |
|---|---|---|
| `Пользователь` | СправочникСсылка.Пользователи | Агент, чьё положение зафиксировано. |

**Ресурсы** (координаты строкой — как везде в обмене, без потери точности):

| Имя | Тип | Назначение |
|---|---|---|
| `Широта` | Строка (20, перем.) | GPS-широта точки. |
| `Долгота` | Строка (20, перем.) | GPS-долгота точки. |
| `Точность` | Строка (16, перем.) | Точность фикса в метрах (для отсева «прыжков»). |

Период записи = момент съёма на телефоне. Идемпотентность встроенная: повтор
той же точки (агент+момент) перезаписывает, дубль не появляется.

## После создания

1. Учётке обмена права на регистр **не** выдавать — обработчик пишет его
   привилегированно (`SmartSale_Обмен.ЗаписатьТочкуТрека`).
2. Роли того, кто смотрит трек (просмотрщик-АРМ), дать **чтение**
   `SmartSale_ТрекАгента`.
3. Обновить конфигурацию, затем загрузить модули `SmartSale_Обмен` и HTTP-сервис
   `smartsale` (обработчик `agentTrackPOST`, URL-шаблон `/agent_track` уже в
   `HTTPServices/smartsale.xml`).

## Ретенция (хранение 90 дней) — на потом

Трек копится (~200 точек/день на агента). Чистку старше 90 дней проще всего
сделать регламентным заданием расширения (удалять записи регистра с
`Период < ТекущаяДата - 90 дней`). В v1 не делаю — регистр это выдержит; заведём
регламент отдельным шагом, когда объём начнёт мешать.

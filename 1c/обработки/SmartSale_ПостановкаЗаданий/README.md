# SmartSale: постановка заданий (АРМ №2)

Внешняя обработка супервайзера: массово ставит задания агенту по его клиентам.
Задание — **типовой документ `ЗаданиеТорговомуПредставителю`** (не свой объект):
шапка агент+клиент+дата визита+статус «К отработке», ТЧ «Задачи» с текстом.
Пишется программно (`Записать` без проведения) — проверка заполнения не
запускается, соглашения в базе выключены, документ создаётся минимальным набором.

## Что делает
1. Выбираешь агента (и опц. фильтр по имени) → «Подобрать клиентов» → таблица его
   клиентов (по `Партнер.ОсновнойМенеджер`).
2. Пишешь текст задания и дату визита, отмечаешь клиентов.
3. «Поставить задания» — по каждому отмеченному создаётся
   `ЗаданиеТорговомуПредставителю` (агент, клиент, дата, статус «К отработке»,
   задача с текстом). Каждый клиент — своя транзакция, результат в протоколе.

## Сборка
```
powershell -File "...\Обработки\ERP\build.ps1" -Name SmartSale_ПостановкаЗаданий `
  -Srvr "localhost\erp_test" -Platform "C:\Program Files\1cv8\8.3.27.2130\bin\1cv8.exe"
```

## Запуск
Открыть `.epf` в ut milk (Файл→Открыть) или подключить доп.обработкой. Права:
запись `ЗаданиеТорговомуПредставителю`.

## Связанное (переход на типовой документ — в работе)
Обмен с телефоном перерабатывается на `ЗаданиеТорговомуПредставителю` (вместо
`SmartSale_Задания`, который сносим); фото визита цепляется к присоединённым файлам
ДОКУМЕНТА (`ЗаданиеТорговомуПредставителюПрисоединенныеФайлы`), а не к партнёру.

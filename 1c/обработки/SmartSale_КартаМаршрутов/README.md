# SmartSale: карта и маршрут (АРМ №1)

Внешняя обработка супервайзера: показывает клиентов агента на карте по их
координатам (из контактной информации контрагента — том же источнике, что
отдаёт `/customers`), даёт собрать **маршрут обхода** и **присвоить его агенту
на день недели** (регистр `SmartSale_Маршруты` → дальше в приложение обменом).

## Что делает
1. Выбираешь **агента** и **день недели** → «Загрузить»: в таблицу «Клиенты
   агента» встают его клиенты с координатами, а из регистра подтягивается уже
   сохранённый маршрут на этот день.
2. **Собираешь маршрут**: отмечаешь клиентов в списке → «Добавить в маршрут»;
   в таблице «Маршрут» правишь порядок кнопками **Вверх / Вниз / Удалить**.
   Колонка «№» — позиция обхода.
3. **Карта показывает** маршрут: точки маршрута — нумерованные маркеры,
   соединённые линией; остальные клиенты агента — серые точки. «Показать на
   карте» перерисовывает карту по текущему списку. В панели — число точек и
   длина; при ≥2 точках — ссылки «Открыть в Яндекс/Google Картах» (маршрут по
   дорогам с поворотами).
4. **«Сохранить маршрут»** — пишет набор записей в `SmartSale_Маршруты`
   (Пользователь=агент, ДеньНедели, Партнёр, Порядок), **замещая** прежний
   маршрут агента на этот день. Уходит в приложение штатным обменом.

## Как устроено (и ограничения)
- Источник порядка — **таблица на форме 1С**, карта только показывает (клик по
  карте маршрут не правит). Так надёжно и тестируемо — двустороннего моста 1С↔JS
  нет (в отличие от Моби-С с `Router.dll` + мостом).
- Карта — **Поле HTML-документа + Leaflet** (CDN unpkg), тайлы **OpenStreetMap**.
  ⚠ Только **ТОНКИЙ клиент**, нужен **интернет** на рабочем месте.
- Координаты клиентов пишет агент на визите (и АРМ приёма заявок) — у кого
  координат нет, тот в списке есть, но на карте не показывается.
- Реальный маршрут по дорогам отдаём внешним картам по ссылке; на самой карте —
  прямые между точками (движок Моби-С `Router.dll` не тащим).

## Проверено
- Отрисовка карты (маршрут по порядку из списка, серые не-маршрутные точки,
  линия, длина, ссылки, авто-зум по всем точкам) — в браузере.
- Логика формы (запись набора в регистр с замещением по агент+день; правка
  порядка через идентификаторы строк, а не индексы; имя реквизита дня НЕ
  занимает функцию `ДеньНедели()`) — самопроверка + адверсариальное ревью в
  свежем контексте, оба блокера исправлены. Интерактивно в 1С не гонялось (MCP
  только чтение) — приёмка за тобой.

## Загрузка обновления
Форма изменилась структурно (новые реквизиты и таблицы) — **не** обновить только
модуль: нужно заменить обработку целиком (переимпортировать `.epf` во встроенную
обработку расширения, либо загрузить корректно из выгрузки).

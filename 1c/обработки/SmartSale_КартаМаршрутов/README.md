# SmartSale: карта клиентов (АРМ №1)

Внешняя обработка: показывает клиентов выбранного агента на карте по их
координатам (из контактной информации контрагента — том же источнике, что
отдаёт `/customers` и куда пишет уточнение координат с телефона), и строит по
выбранным точкам маршрут объезда.

## Что делает
1. Выбираешь агента → «Показать на карте».
2. Клиенты с координатами появляются маркерами на карте OpenStreetMap; клик по
   маркеру — название точки. В протоколе — сколько клиентов и сколько с
   координатами.
3. **Маршрут по выбранным точкам**: кликай маркеры в нужном порядке — точки
   нумеруются (1, 2, 3…), между ними рисуется линия, в панели — число точек и
   длина (прямая между точками). Повторный клик по точке убирает её и
   перенумеровывает; «Сбросить маршрут» очищает.
4. **Навигация по дорогам**: когда выбрано ≥2 точек, в панели появляются ссылки
   «Открыть в Яндекс.Картах» / «Открыть в Google Картах» — там маршрут строится
   уже по дорогам с поворотами (движок Моби-С `Router.dll` не тащим — реальный
   маршрут отдаём внешним картам).

## Как устроено (и ограничения)
- Карта — **Поле HTML-документа + Leaflet** (загружается с CDN unpkg), тайлы
  **OpenStreetMap**. Точки **вшиты в HTML** при формировании на сервере — рантайм-
  моста 1С↔JS нет, поэтому надёжно.
- ⚠ **Только ТОНКИЙ клиент** (в веб/мобильном клиенте HTML-поле так не
  отрисует). Нужен **интернет на рабочем месте** (библиотека Leaflet и тайлы
  качаются из сети; у вас провайдер режет подсеть VPS — тайлы идут с машины
  оператора, это ок).
- Координаты у клиентов проставляет агент на визите — сейчас их немного, поэтому
  точек на карте может быть мало.

Построение маршрута — целиком в JS страницы (без обращений в 1С), протестировано
в браузере (выбор/порядок/линия/длина/ссылки/сброс). fitBounds вызывается с
повтором, пока у HTML-поля не появится размер, — иначе карта осталась бы на
нулевом зуме (мире).

## v2 (интерактив с сохранением — позже)
Сохранение построенного маршрута обратно в 1С (порядок посещения в настройку
агента), правка координат кликом, перетаскивание маркеров — требует двустороннего
моста 1С↔JS (скрытые кнопки + OnClick), как у Моби-С. Сейчас маршрут строится и
используется на месте (просмотр + передача во внешние карты).
